# 🏠 Freedom Voucher Network

**A decentralized housing assistance platform leveraging blockchain to power transparent, portable, and interoperable voucher administration.**

## Overview

The Freedom Voucher Network (FVN) is an open-source framework that reimagines how housing assistance is distributed and managed across public and private sectors. Built on blockchain technology, FVN enables:

- **Voucher Portability** across jurisdictions
- **Smart Contract Automation** for rent payments and compliance
- **Real-Time Transparency** for PHAs, landlords, and tenants
- **Fraud Reduction** through immutable transaction records
- **Interoperability** between PHAs, health systems, employers, and service providers

## Core Features

- 🔗 **Blockchain Infrastructure**  
  Ethereum-compatible smart contracts govern voucher issuance, redemption, and compliance rules.

- 👤 **Tenant-Centric Wallets**  
  Digital voucher wallets tied to identity credentials and compliance milestones.

- 🏘️ **Landlord Portals**  
  Accept, track, and redeem vouchers with instant payment verification and smart contract triggers.

- 🏛️ **PHA & Agency Dashboard**  
  Analytics, risk scoring, and voucher tracking across partner networks.

## Use Cases

- Cross-state voucher transfers
- Employer-assisted housing stipends
- Health-to-housing prescription pilots
- Portability for formerly incarcerated or homeless individuals
- Disaster-response rental assistance

## Tech Stack

- **Smart Contracts**: Solidity / EVM-compatible chain
- **Backend**: Node.js, TypeScript, PostgreSQL
- **Identity Layer**: Decentralized Identifiers (DIDs), zk-proof verification
- **Frontend (Demo)**: React, Next.js, Tailwind CSS
- **Oracles**: Chainlink (for rent indexing and compliance validation)

## Roadmap

1. ✅ Proof-of-Concept smart contract for voucher issuance  
2. ✅ Demo interface for PHA + landlord voucher flow  
3. 🔜 DID-based tenant onboarding module  
4. 🔜 Partner integration: housing authorities + health orgs  
5. 🔜 Federated governance prototype

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/[your-org]/freedom-voucher-network.git
cd freedom-voucher-network
npm install
````

Start the local development environment:

```bash
npm run dev
```

Smart contract deployment:

```bash
npx hardhat run scripts/deploy.js --network localhost
```
